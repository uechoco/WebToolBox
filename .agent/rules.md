# Project Rules

## General

- **Communication Language**: Always respond in Japanese.

## Coding Standards

- **Version Control**: Git
- **Programming Language**: Pure JavaScript
- **Code Style**: 
   - **Indentation**: 2 spaces
   - **Line Length**: 120 characters
   - **Line Break**: Unix (LF)
   - **Quote Style**: Single quotes
   - **Spacing**: Single space after commas and colons
   - Use `const` by default
   - Use `let` only when you need to reassign a variable

## Testing

- When testing, use `npx serve` and access the files through the browser due to the CORS issue.
